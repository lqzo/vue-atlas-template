# Vue Atlas Template

Vue Atlas Template is the clean starter for modern Vue admin applications.

It is designed as the smallest production-ready entry in the Vue Atlas family. Use it when you want a simple project structure and a stable admin foundation without the full showcase modules.

## Features

- Vue 3 + TypeScript + Vite
- Vue Router 5 route-driven menu and permission metadata
- Pinia user and permission stores
- Element Plus components and styles are imported on demand
- Axios request foundation
- Minimal pages for login, dashboard and 404

## Project Structure

```text
src/
  api/          API modules
  directives/   global directives
  layout/       admin shell
  pages/        route pages
  router/       routes, guards, menu generation
  stores/       Pinia stores
  styles/       global styles
  utils/        shared utilities
```

## Scripts

```bash
pnpm install
pnpm dev
pnpm build
pnpm test
```

`src/auto-imports.d.ts` and `src/components.d.ts` are generated by Vite plugins during development and build.
